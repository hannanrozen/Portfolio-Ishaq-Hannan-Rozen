# Ishaq Hannan Rozen — QA Engineer Portfolio

Personal portfolio built with React 19, Vite, and Tailwind CSS v4.

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run lint     # ESLint
npm test         # Playwright smoke tests (desktop + mobile Chromium)
```

## Content

All copy lives in `src/data/profile.js` — keep it in sync with the CV in `Doc/`.
The downloadable resume is served from `public/CV_Ishaq_Hannan_Rozen_QA_2026.pdf`.
